## 📖 About the Project

**Kevin Inks** is a premium portfolio and personal-brand website created for a tattoo artist.

The website uses a dark luxury aesthetic, bold editorial typography, professional photography, and smooth animations to present the artist’s work as a high-end creative experience.

Visitors can explore completed tattoos, browse original available designs, learn about the artist’s process, discover the story behind the brand, and access booking and social-media links.

> **Portfolio project:** This website demonstrates the design and development of a complete digital brand experience for a professional artist.

## 🖼️ Website Sections

### 🏠 Hero

A cinematic introduction that establishes the Kevin Inks brand and directs visitors toward the artist’s work, booking options, and social presence.

### 🎨 Selected Work

A visual portfolio displaying completed tattoo pieces across styles such as:

* Fine line
* Black and grey
* Illustrative
* Blackwork
* Micro realism

### 💎 Available Designs

A curated collection of original tattoo concepts with:

* Availability status
* Recommended placement
* Suggested dimensions
* Enlarged design previews
* One-of-one exclusivity

### 🖋️ The Experience

A detailed presentation of the client journey, including consultation, original design, the private tattoo session, and long-term artwork care.

### 👤 About the Artist

A personal brand section introducing Kevin, his artistic philosophy, professional approach, and dedication to meaningful custom artwork.

### 📬 Email Community

A promotional signup experience for early access to design releases, booking availability, and the stories behind new pieces.

### 📅 Booking

A focused call-to-action section designed to turn interested visitors into prospective clients.

## 🎨 Design System

The website uses a carefully selected dark luxury color palette:

| Color     | Usage                |
| --------- | -------------------- |
| `#0F0F0F` | Primary background   |
| `#171717` | Secondary background |
| `#F5F1EA` | Primary text         |
| `#CFC3B0` | Champagne accent     |
| `#8D6E63` | Bronze accent        |
| `#7A1F1F` | Oxblood accent       |
| `#A32C2C` | Crimson accent       |

The restrained palette, oversized typography, subtle textures, and generous spacing create a premium gallery-like presentation that keeps the artwork at the center of the experience.
